# Paleta propuesta: verde petróleo + terracota

La propuesta mantiene la estructura visual de Lezato y usa una base tranquila para trabajar varias horas con pedidos y cifras. La elección es una recomendación de diseño para este restaurante, no una garantía de mayor venta.

| Uso | Color | HEX |
|---|---|---|
| Acciones principales, navegación y gráficos | Verde petróleo | `#087F73` |
| Acciones destacadas y acentos | Terracota | `#D76B4A` |
| Texto principal | Gris profundo | `#27343B` |
| Fondo general | Gris muy claro | `#F7F8FA` |
| Tarjetas y menú | Blanco | `#FFFFFF` |
| Estados pendientes y avisos | Ámbar | `#BC851B` |
| Indicadores secundarios | Violeta tenue | `#7360B4` |
| Errores y anulación | Rojo | `#C24650` |

El verde identifica acciones del sistema; el terracota conserva un tono cálido asociado a la comida. Las tarjetas blancas separan los grupos de información y el texto oscuro permite leer cifras sin competir con los gráficos. Los estados llevan texto además de color.

En **Configuración y respaldo → Paleta de colores** también se puede elegir **Naranja Lezato**. Mantiene la misma distribución y usa naranja para las acciones y violeta como acento. Guarda la configuración para aplicar la selección.

Las variables de color están al inicio de `src/styles.css`. Las fuentes van incluidas, sin depender de Google Fonts al abrir el sitio.
